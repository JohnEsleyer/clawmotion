Built for AI Agents & High-Performance Backends

Designed from the ground up for zero-friction LLM code generation and headless server efficiency.

01

Zero-Puppeteer Pipeline

Node.js & Bun server rendering uses skia-canvas C++ bindings directly to FFmpeg. No heavy Chrome binaries or memory spikes.

02

Agent-Native Schemas

Define blueprints using Zod schemas with defineBlueprint. Auto-export tool definitions for AI Function Calling with 100% type safety.

03

Analytical Spring Physics

Built-in analytical spring solver (utils.spring) computes exact closed-form spring motion at any frame without numerical history.

04

Agentic Vision Feedback

Run clawmotion audit to extract keyframe PNG snapshots and JSON reports for Vision models (GPT-4o, Gemini) to self-correct layouts.

05

Mathematical Parity

Seeded pseudo-random number generator (ClawMath) guarantees frame-for-frame identity across browser previews and headless servers.

06

Pre-Baked Audio FFT

Offline FFT audio analyzer bakes frequency bins per frame before rendering, avoiding live audio clock drift during playback.

Pure TypeScript API

Define Motion with Type-Safe Blueprints

Blueprints are pure functions. Pass parameter schemas with Zod, compute spring physics, and render using the standard 2D Canvas context.

+ Isomorphic Execution (Node, Bun, Browser)
+ Auto-Validated Props with Defaults
+ Instant Function Calling Export for AI
blueprints/SpringBox.ts TypeScript 
import { defineBlueprint } from '@johnesleyer/clawmotion/core';
import { z } from 'zod';

export const SpringBox = defineBlueprint({
  id: 'spring-box',
  schema: z.object({
    color: z.string().default('#22d3ee'),
    stiffness: z.number().default(200)
  }),
  run: (ctx) => {
    const { ctx: c, width, height, time, utils, props } = ctx;

    // Analytical Spring Physics
    const scale = utils.spring({
      from: 0, to: 1.5,
      time: time,
      stiffness: props.stiffness
    });

    c.save();
    c.translate(width / 2, height / 2);
    c.scale(scale, scale);
    c.fillStyle = props.color;
    c.fillRect(-50, -50, 100, 100);
    c.restore();
  }
});
